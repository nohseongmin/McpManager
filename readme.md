# McpManager: 사용자 매뉴얼

McpManager는 Gemini CLI와 관련 MCP(Model Context Protocol) 서버의 설치 및 관리를 간소화하는 Windows 데스크톱 애플리케이션입니다. 이 매뉴얼은 McpManager의 모든 기능을 효과적으로 사용하는 방법을 안내합니다.

## 1. 주요 기능

*   **원클릭 설치:** Node.js와 Gemini CLI를 버튼 클릭 한 번으로 쉽게 설치합니다.
*   **간편한 MCP 관리:** GUI를 통해 Github, Google Drive 등 다양한 MCP 서버를 손쉽게 설치하고 삭제합니다.
*   **API 키 관리:** MCP 서버에 필요한 API 키를 안전하게 입력하고 관리합니다.
*   **다국어 지원:** 한국어와 영어를 지원하여 사용자의 편의성을 높였습니다.
*   **직관적인 UI:** 현재 설치 상태와 다음 진행 단계를 명확하게 안내합니다.

## 2. 시스템 요구 사항

*   **운영체제:** Windows 10 이상
*   **권한:** 프로그램 설치를 위해 관리자 권한이 필요합니다.

## 3. 설치 및 설정

Gemini CLI를 사용하기 위한 필수 구성 요소를 설정하는 과정입니다.

### 3.1. Node.js 설치

1.  애플리케이션 좌측의 **[Gemini CLI 설정]** 패널에서 **[Node.js 설치]** 버튼을 클릭합니다.
2.  '사용자 계정 컨트롤(UAC)' 팝업에서 **[예]**를 선택하여 관리자 권한을 부여합니다.
3.  설치가 완료되면 버튼 텍스트가 **"Node.js (설치됨)"**으로 변경됩니다.

### 3.2. Gemini CLI 설치

1.  Node.js 설치 후 활성화된 **[Gemini CLI 설치]** 버튼을 클릭합니다.
2.  다시 나타나는 '사용자 계정 컨트롤(UAC)' 팝업에서 **[예]**를 선택합니다.
3.  설치가 끝나면 버튼 텍스트가 **"Gemini CLI (설치됨)"**으로 업데이트됩니다.

### 3.3. Gemini CLI 실행

1.  모든 구성 요소가 설치되면 **[Gemini CLI 실행]** 버튼이 활성화됩니다.
2.  버튼을 클릭하면 Gemini CLI가 적용된 새로운 PowerShell 터미널이 열립니다.

## 4. MCP 서버 관리

MCP 서버를 추가하여 Gemini CLI의 능력을 확장하세요.

### 4.1. MCP 서버 설치

1.  우측 **[MCP 서버 관리]** 목록에서 원하는 서버(예: Github MCP)를 찾습니다.
2.  해당 항목의 '작업' 열에 있는 **[설치]** 버튼을 누릅니다.
3.  API 키 입력 팝업창이 나타나면, 발급받은 키를 입력하고 **[확인]**을 클릭합니다.
    *   **도움말:** API 키 발급 방법은 팝업창 내의 "API 키 발급 방법 안내" 링크를 통해 확인할 수 있습니다.
4.  설치가 성공적으로 완료되면, 서버의 '상태'가 **"설치됨"**으로 바뀌고 '작업' 버튼은 **"삭제"**로 변경됩니다.

### 4.2. MCP 서버 삭제

1.  삭제할 서버 항목의 '작업' 열에서 **[삭제]** 버튼을 클릭합니다.
2.  삭제 여부를 묻는 확인 창에서 **[예]**를 선택하면 즉시 삭제됩니다.

## 5. 기타 기능

*   **언어 변경:** 우측 상단의 드롭다운 메뉴에서 '한국어' 또는 'English'를 선택하여 UI 언어를 실시간으로 변경할 수 있습니다.
*   **상태 표시줄:** 애플리케이션 하단의 상태 표시줄을 통해 현재 진행 중인 작업과 그 결과를 확인할 수 있습니다.

## 6. 자주 묻는 질문 (FAQ)

**Q: 버튼이 비활성화되어 클릭할 수 없습니다.**
A: 설치 과정은 순서대로 진행해야 합니다. 예를 들어, 'Gemini CLI 설치' 버튼은 'Node.js'가 먼저 설치되어야 활성화됩니다.

**Q: API 키는 어디에 저장되나요? 안전한가요?**
A: API 키는 사용자의 로컬 PC에 위치한 Gemini CLI 설정 파일(`%USERPROFILE%\.gemini\settings.json`)에 저장됩니다. 외부 서버로 전송되지 않으므로 안전합니다.

**Q: 설치 중 오류가 발생했습니다. 어떻게 해야 하나요?**
A: 인터넷 연결 상태를 확인하고, 잠시 후 다시 시도해 보세요. 문제가 지속될 경우, 프로그램을 완전히 종료한 후 관리자 권한으로 다시 실행해 보시기 바랍니다.
